# Rock-Paper-Scissors
Play a best of 3 game of rock paper scissors with the computer

Import:
- random

Input: 
- player choices

Output: 
- player/computer wins round
- player/computer wins tournament

Ex:
- input: rock
- output: computer wins round
- input: scissors
- output: player wins round
- input: scissors
- output: player wins round
- output: player wins!
